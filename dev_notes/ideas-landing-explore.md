# 아이디어 정리 — 메인 랜딩 애니메이션 / Explore 디자인·기능

> 브레인스토밍 목록(미구현). 각 항목 끝의 표기: 효과(임팩트)/난이도. 🧱 = 블록·복셀 테마 살린 차별화 아이디어.
> 현재 메인엔 시네마틱 인트로·글자 흩어짐·패럴랙스·InfiniteMarquee·커스텀커서·섹션 점 내비가 이미 있음.
> 현재 explore는 3탭(작품 feed / WIP 로그 / 크리에이터) + 검색·카테고리·정렬(최신/인기)·커미션 필터.

---

## 1. 메인 — 등장(Entrance) 애니메이션

1. **블록 빌드 프리로더** 🧱 — 복셀 큐브들이 쌓여 로고/타이틀을 조립하며 등장 → 히어로로 전환. 로딩% 카운터 결합. (높음/중)
2. **첫 방문 vs 재방문 분기** — 첫 방문만 풀 시네마틱(localStorage), 재방문은 빠른 페이드. reduced-motion 존중. (높음/하)
3. **클립패스 와이프 리빌** — 색 패널이 쓸려나가며 히어로 노출(블록 격자 모양 와이프면 테마 일치). (중/하)
4. **마스크 확장 이미지 리빌** — 원/블록 마스크가 커지며 히어로 이미지 공개. (중/중)
5. **헤드라인 디코드** — 부제목을 ScrambleText(이미 보유)로 해킹체→정자 해독. (중/하)
6. **스태거 캐스케이드** — 태그·CTA·내비를 시간차로 순차 등장(현재 글자 위주 → 주변 요소까지 확장). (중/하)
7. **커서 반응 히어로** — 로드 직후 배경 격자/파티클이 마우스 따라 시차 이동(생동감). (중/중)
8. **스크롤 힌트** — 인트로 끝에 "스크롤 유도" 인디케이터(바운스 화살표/마우스 휠) 페이드인. (낮음/하)
9. **글리치/스캔라인 전환** — 인트로→히어로 사이 짧은 글리치 한 프레임(취향 탈 수 있음). (낮음/중)

## 2. 메인 — 스크롤 애니메이션

1. **핀(Pin) 스토리텔링** — "어떻게 작동하나 3스텝"을 한 섹션에 고정한 채 스크롤로 단계 전환(GSAP pin). (높음/중)
2. **가로 스크롤 갤러리** — 세로 스크롤이 추천 작품/크리에이터를 가로로 흘려보냄. (높음/중)
3. **숫자 카운트업** — 총 크리에이터·총 작품·누적 조회수가 뷰 진입 시 0→실수치로 카운트. (높음/하, 실데이터 연동)
4. **다층 패럴랙스 뎁스** — 전경/중경/배경 다른 속도로 이동해 입체감 강화. (중/중)
5. **카드 스태거 리빌** — 작품/크리에이터 카드가 뷰 진입 시 순차 페이드·슬라이드업(ScrollReveal 보유). (중/하)
6. **세로 라인 드로잉** — 스크롤에 맞춰 타임라인 선이 그려짐(ScrollFillText 보유 활용). (중/중)
7. **배경 테마 시프트** — 스크롤 진행에 따라 배경색/그라데이션이 서서히 전환. (중/하)
8. **마키 스크롤 반응** — InfiniteMarquee 속도·방향이 스크롤 속도/방향에 반응. (중/중)
9. **스크롤 스냅** — 스테이지 간 풀페이지 스냅(섹션 내비와 연동). (중/중, UX 호불호)
10. **스크롤 속도 기반 카드 틸트** — 스크롤 가속도에 따라 카드 미세 회전. (낮음/중)
11. **고정 CTA 등장** — 히어로 지나면 "지금 시작하기" 버튼이 하단/상단에 sticky 등장. (중/하)
12. **크리에이터 스포트라이트 모핑** — 스크롤하며 추천 크리에이터가 부드럽게 교체/모핑. (중/높음)

## 3. /explore — 디자인

1. **메이슨리(핀터레스트) 피드** — 썸네일 높이 가변 배치로 더 다이내믹하게. (높음/중)
2. **카드 호버 퀵프리뷰** — 호버 시 카드 확장 + 미니 이미지 캐러셀/설명 살짝 노출. (높음/중)
3. **퀵룩 모달** — 카드 클릭 시 explore 안 떠나고 모달로 빠르게 미리보기. (높음/중)
4. **상단 베스트 베이스(Bento)** — 피드 위에 "에디터 픽/이주의 작품" 벤토 그리드. (중/중)
5. **태그 칩** — #3D #건축 #인테리어 등 클릭형 칩으로 즉시 필터. (높음/중, 태그 기능 필요)
6. **스티키 필터바** — 정렬·카테고리·검색 바가 스크롤 시 상단 고정(특히 모바일). (중/하)
7. **스켈레톤 로딩** — 필터/로드 중 쉬머 스켈레톤. (중/하)
8. **탭 전환 애니메이션** — 탭 언더라인 슬라이드 + 콘텐츠 크로스페이드. (중/하)
9. **그리드/리스트 뷰 토글** — 보기 방식 선택. (낮음/하)
10. **크리에이터 카드 리디자인** — 미니 포트폴리오(썸네일 3장)·커미션 상태·조회/작품수 뱃지. (중/중)
11. **다크 모드** — 포트폴리오들이 다크라 explore도 다크 옵션. (중/중)
12. **빈 상태 일러스트** — 검색결과 없음 등 친근한 일러스트 + 추천 액션. (낮음/하)
13. **카드 마이크로 인터랙션** — 리프트·이미지 줌·아바타 슬라이드인·뷰카운트 페이드. (중/하)

## 4. /explore — 기능

1. **태그/키워드 시스템** — 작품에 태그 부여, 태그로 검색·필터(디자인 #5와 연동). (높음/중, 스키마 추가)
2. **이주의 인기/트렌딩** — 기간별 인기 랭킹(실 조회수 추이 → `ProjectView` 로그 테이블 필요). (높음/중)
3. **북마크/팔로우** — 크리에이터·작품 저장, 팔로우(저장 테이블 + 로그인). (높음/중)
4. **정렬 확장** — 조회수순/최신/커미션 가능/댓글순 등. (중/하)
5. **검색 고도화** — 작가·태그·퍼지 매칭, 자동완성, 최근검색어. (중/중)
6. **추천(연관) 작품** — "비슷한 작품", "이 작가의 다른 작품". (중/중)
7. **커미션 마켓 필터** — "커미션 받는 중"만 보기 + 단가/가능여부 표시. (중/중)
8. **공유** — 작품/크리에이터 링크 복사 + OG 카드. (중/하)
9. **무한 스크롤/더보기** — 한 번에 전부 로드 대신 점진 로드(성능). (중/중)
10. **랜덤 탐험** — "랜덤 둘러보기/오늘의 추천" 서프라이즈 버튼. (낮음/하)
11. **카테고리 카운트** — 카테고리별 작품 수 표시. (낮음/하)
12. **개인화 피드** — "내 관심 카테고리" 기반 추천 정렬. (중/높음)
13. **신규 크리에이터/신작 알림** — "이번 주 새 크리에이터" 섹션, 알림. (중/중)
14. **리더보드** — 조회수/작품수 상위 크리에이터 명예의 전당. (중/중)

## 추천 우선순위 (효과 대비 난이도)

**먼저 하면 좋은 것(임팩트↑·난이도↓):**
- 메인: 첫방문/재방문 분기, 숫자 카운트업, 카드 스태거 리빌
- explore: 메이슨리 피드, 카드 호버 퀵프리뷰/퀵룩 모달, 스티키 필터바, 탭 전환 애니메이션

**기반 작업 필요(가치 큼·선행 필요):**
- 태그 시스템(→ 칩 필터·검색 고도화) / `ProjectView` 로그(→ 트렌딩·카운트업 실데이터) / 북마크·팔로우 테이블

**테마 차별화:**
- 🧱 블록 빌드 프리로더 / 블록 격자 와이프 리빌
