# BlockCanvas 서버 이용 가이드

BlockCanvas 마인크래프트 건축 서버와 웹 플랫폼(craftopia.work) 이용 가이드라인입니다. 처음 오셨다면 아래 순서대로 읽어 주세요.

## 목차

1. **[시작하기](getting-started.md)** — 회원가입, Discord·마인크래프트 연동, 서버 접속
2. **[영토(플롯)와 월드 클라우드](plots-and-worlds.md)** — 플롯 분양·초대·경매, 개인 월드 업로드/백업
3. **[인게임 명령어와 등급](commands-and-ranks.md)** — 자주 쓰는 명령어, 등급별 권한·용량
4. **[커뮤니티·코인과 규칙](community-and-rules.md)** — 커뮤니티/코인, 서버 규칙·매너, 문의

## 한눈에 보기

- **가입**: 이메일 또는 Discord 로그인
- **연동**: 마인크래프트 정품(Microsoft 로그인 권장) + Discord
- **접속**: 마인크래프트 자바 에디션 정품 클라이언트 (서버 주소는 Discord 공지 참고)
- **건축 공간**: 영토(플롯) / 개인 월드 클라우드
- **규칙 요약**: 테러·그리핑 금지 · 핵/치트 금지 · 서버 렉 유발 금지 · 서로 존중
