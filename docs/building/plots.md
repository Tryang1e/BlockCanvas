# 영토(플롯)

영토(플롯)는 다른 사람의 방해 없이 건축할 수 있는 개인 공간입니다.

## 플롯 월드 종류

플롯 크기별로 여러 월드가 있습니다. 큰 플롯일수록 분양가(코인)가 높습니다.

| 월드 | 플롯 크기 |
| --- | --- |
| 기본 | 100×100 |
| 대형 | 300×300 |
| 특대 | 500×500 |
| 초대형 | 1000×1000 |

{% hint style="info" %}
인게임에서 `/탐방` 으로 **탐방 가능 월드** 메뉴를 열어 각 플롯 월드를 둘러볼 수 있습니다.
{% endhint %}

## 분양받기

빈 플롯을 **분양(claim)** 받아 건축을 시작합니다. 분양가는 월드(플롯 크기)에 따라 다르며, 보유 가능한 플롯 수는 [등급](../reference/ranks.md)에 따라 다릅니다. Dynmap에서 빈 플롯(초록 마커)을 클릭하면 분양가가 표시됩니다.

## 초대·신뢰

함께 건축할 멤버를 초대해 권한을 부여할 수 있습니다.

{% hint style="info" %}
초대받은 플롯에서 나가려면 웹 대시보드에서 **\[나가기]** 를 누르세요.
{% endhint %}

## 양도·경매

* **양도** — 플롯을 다른 이용자에게 넘깁니다.
* **경매** — 코인으로 거래합니다. Dynmap에서 마커 색으로 상태를 확인할 수 있습니다.

| 마커 색 | 상태 |
| --- | --- |
| 🟢 초록 | 빈 플롯 (분양 가능) |
| 🔵 파랑 | 점유 중 |
| 🟠 주황 | 경매 중 (클릭해서 구매) |

## 주요 명령어

| 명령어 | 설명 |
| --- | --- |
| `/플롯 메뉴` | 영토 관리·안내 허브 메뉴를 엽니다. |
| `/플롯 구매` | 서 있는 빈 영토를 분양받습니다. (Dynmap 초록 마커 클릭으로도 가능) |
| `/플롯 초대 <플레이어>` | 함께 건축할 멤버를 신뢰(트러스트)합니다. |
| `/플롯 홈` | 내 영토 목록에서 골라 이동합니다. |
| `/플롯 수락` · `/플롯 거절` | 받은 소유권 양도를 수락/거절합니다. |

플롯 관련 전체 명령어(분양·멤버·설정·양도 등)는 [인게임 명령어](../reference/commands.md)에서 확인하세요.

{% hint style="danger" %}
권한이 없는 타인의 플롯·건축물을 무단으로 변경·파괴하는 행위는 [이용약관 제6조](https://craftopia.work/terms)에 따라 **엄격히 금지**됩니다.
{% endhint %}
