# 월드 클라우드

개인 월드를 웹에 업로드·백업하고, 인게임에서 입장해 작업할 수 있는 클라우드 기능입니다.

## 웹에서

대시보드에서 월드 **.zip 업로드 / 다운로드 / 백업**을 관리합니다.

## 인게임에서

`/월드` 명령어로 보유·초대된 월드 목록을 열어 입장할 수 있습니다.

| 명령어 | 설명 |
| --- | --- |
| `/월드` | 보유·초대된 월드 목록을 엽니다. |
| `/월드 입장 <번호>` | 목록의 N번째 월드로 입장합니다. |
| `/탐방` | 다른 유저가 공유한 월드를 둘러봅니다. |

월드 관련 전체 명령어는 [인게임 명령어](../reference/commands.md)에서 확인하세요.

{% hint style="info" %}
저장 용량(쿼터)은 [등급](../reference/ranks.md)에 따라 다릅니다.
{% endhint %}

## 수명주기 (보관·삭제)

서버 자원을 위해, 오래 사용하지 않은 월드는 자동으로 정리됩니다. **계속 사용하면 기한이 자동으로 갱신**되니 평소에는 신경 쓰지 않아도 됩니다.

| 단계 | 시점 | 동작 |
| --- | --- | --- |
| 활성 | 사용 중 | 정상 입장·편집. 입장할 때마다 보관 기한이 갱신됩니다. |
| 비활성화(보관) | **마지막 사용 30일 후** | 백업으로 보관되고 서버에서 내려갑니다. (대시보드에서 직접 비활성화도 가능) |
| 영구 삭제 | **비활성화 90일 후** | 백업까지 완전히 삭제됩니다. |

{% hint style="warning" %}
방치하면 마지막 사용일로부터 **최대 120일(30 + 90)** 뒤 영구 삭제됩니다. 직접 비활성화한 경우 그날부터 90일 뒤 삭제됩니다.
{% endhint %}

{% hint style="info" %}
보관(비활성화) 상태인 월드는 영구 삭제 전이라면 대시보드에서 다시 **활성화**해 복구할 수 있습니다.
{% endhint %}
