# 플롯 구매/삭제

### 플롯 구매&#x20;

![](<../../.gitbook/assets/image (24).png>)

먼저 구매 점유 플롯이 활성화된 상태에서&#x20;

<figure><img src="../../.gitbook/assets/image (25).png" alt=""><figcaption></figcaption></figure>

다음과 같이 초록색, 파란색 네모칸을 확인할 수 있습니다.\
초록색 네모칸의 경우 구매할 수 있는 플롯을 의마하고\
파란색 네모칸의 경우 점유된 플롯을 의미합니다.

#### 초록색 네모칸을 클릭시

<figure><img src="../../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>

구매 가격과 함께 영토 정보가 함께 표시됩니다.

#### 파란색 네모칸을 클릭시

<figure><img src="../../.gitbook/assets/image (26).png" alt=""><figcaption></figcaption></figure>

다음과 같이 해당 점유된 플롯의 정보가 표시됩니다.

이제 플롯을 구매하게되면 코인이 차감되고 해당 영토에 대한 소유권을 받습니다.

<figure><img src="../../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>

구매 후 "동기화" 버튼을 누르게되면 이처럼 본인이 보유한 플롯과 해당 플롯에 대한 정보를 확인할 수 있습니다.

### 플롯 삭제

<figure><img src="../../.gitbook/assets/image (36).png" alt=""><figcaption></figcaption></figure>

맨 아래 버튼 플롯 삭제를 누르면 플롯이 삭제됩니다.

{% hint style="danger" %}
삭제 버튼을 누르면 해당플롯의 모든 건축물이 사라지니 신중하게 클릭하시기 바랍니다.
{% endhint %}
