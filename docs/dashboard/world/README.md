# 건축 대시보드 ( 월드 )

월드의 경우 본인 건축대시보드의 사이드탭에서 확인할 수 있습니다.

본인 월드의 최대용량은 [ranks.md](../../undefined-1/ranks.md "mention")을 확인하세요.

<figure><img src="../../.gitbook/assets/image (51).png" alt="" width="221"><figcaption></figcaption></figure>

* 본인의 월드는 상단
* 초대된 월드의 경우 '초대된 월드' 카테고리와 함께 하단

다음과 같이 표시됩니다.

### 월드 생성/삽입

월드를 생성/삽입하려면 사이드탭의 '+ 생성' 버튼을 클릭합니다.

<div><figure><img src="../../.gitbook/assets/image (52).png" alt="" width="343"><figcaption></figcaption></figure> <figure><img src="../../.gitbook/assets/image (53).png" alt="" width="337"><figcaption></figcaption></figure></div>

그러면 다음과 같이 창이 하나 뜨게됩니다.&#x20;

* 기본생성의 경우
  * 기본 평지맵 혹은 야생맵을 생성할 수 있으며 구조물 생성을 추가하거나 해제할 수 있습니다.
* 월드삽입의 경우
  * 본인이 보유한 월드 파일을 업로드해 서버에 등록할 수 있습니다.
  * 단 해당 업로드는 월드 파일을 압축된 형태의  `.zip` 파일 형태여야합니다.&#x20;

{% hint style="danger" %}
이때 월드 파일이 아니거나 모드로 생성된 월드파일, 데이터팩이 포함된 월드파일의 경우 업로드불가능합니다.
{% endhint %}

이후 월드를 생성/삽입하게되면,&#x20;

<figure><img src="../../.gitbook/assets/image (54).png" alt=""><figcaption></figcaption></figure>

월드 대시보드가 표시됩니다.

월드 생성정보와 함께&#x20;

* 인게임 입장
  * 본인을 해당월드로 텔레포트합니다.
* 백업
  * 본인의 월드를 백업할 수 있습니다. \
    ( 단, 백업 용량은 5번이며 5번을 초과시 마지막 백업이 삭제되고 새롭게 백업이 등록됩니다. )
* 비활성화
  * 본인의 월드를 비활성화하게 되면 아카이브 형태로 월드가 비활성화되고 90일 이후 자동삭제됩니다.
* 삭제
  * 본인의 월드를 삭제합니다.

{% hint style="danger" %}
30일 미접속 시 강제로 맵파일의 경우 비활성화되며 90일 이후 자동 삭제됩니다. ( 유예기간 30일+90일=120일 )
{% endhint %}

월드 탐방의 경우 서버내 `/탐방` 명령어를 통해 표시되며

탐방 공유 진행시 다음과 같은 안내사항이 표시됩니다.

<figure><img src="../../.gitbook/assets/image (61).png" alt="" width="340"><figcaption></figcaption></figure>

이처럼 Axiom의 clipboard나 FAWE의 //copy의 경우 방지할 수 있는 Litematica 혹은 미니맵과 같은 모드의경우 방지가 힘듭니다. 1차적으로 월드다운로더 모드의 방지는 되어있지만 우회시 전부 막기는 힘드니 관련해서 꼭 숙지바랍니다.



이후 다이나믹 맵을 통해 본인의 월드 정보를 확인할 수 있습니다.

* 월드 다이나믹 맵은 시간이지나면 자동으로 표시되며 만약 바로 확인하고싶다면 관리자를 호출하시기바랍니다.

<figure><img src="../../.gitbook/assets/image (55).png" alt=""><figcaption></figcaption></figure>

이후 페이지를 내리게되면 상세한 월드 정보를 확인할 수 있고 게임룰과 월드보호를 설정할 수 있습니다.
