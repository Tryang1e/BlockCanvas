# 월드 설정

<figure><img src="../../.gitbook/assets/image (60).png" alt=""><figcaption></figcaption></figure>

이처럼 게임룰을 ON/OFF 형태로 변경할 수 있으며

월드입장시

* 게임모드
  * 월드 입장시 해당 모드로 변경됩니다.
* 난이도
  * 월드 내 난이도를 설정가능합니다.
* 월드 시간
  * 월드 시간을 설정할 수 있습니다.
* 랜덤 틱 속도
  * 작물이나 묘목 과 같은 성장류 아이템이 변화하는 것을 방지할수 있습니다.

다음은 하단의'월드 보호설정' 을 누르게되면

<figure><img src="../../.gitbook/assets/image (62).png" alt=""><figcaption></figcaption></figure>

다음 화면이 표시됩니다.

* 아이템 버리기 허용
  * 아이템을 버릴 수 있습니다.
* 레드스톤 작동허용
  * 레드스톤 회로를 이용할 수 있습니다. \
    ( 단, 서버에 악영향을 줄 만한 회로 제작시 [이용약관](../../community/rules.md)에 의해 처벌합니다. )
  * 이용하시려면 '블록 물리 중력 자동'을  활성화 하시기  바랍니다.
* 블록 물리 중력 작동
  * 활성화 시 모래나 자갈과 같은 블럭들이 바닥으로 떨어지며
  * 비활성화시 모래나 자갈과 같은 블럭들이 바닥으로 떨어지지 않고 고정됩니다.
* 밟기 파괴 방지
  * 활성화   시경작지, 작물, 거북알 등과 같은 블록들이 파괴 방지됩니다.



**잘못된 기능을 통해 용량이 과부하 시 자동으로 맵은 비활성화되니 꼭 이점 유의 바랍니다.**
