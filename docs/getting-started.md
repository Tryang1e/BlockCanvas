# 1. 시작하기 — 회원가입 · 계정 연동 · 서버 접속

## 회원가입

두 가지 방법으로 가입할 수 있습니다. 어느 쪽으로 시작해도 이후 대시보드에서 나머지 계정을 연동할 수 있습니다.

| 방법 | 설명 |
| --- | --- |
| 📧 **이메일 가입** | 이메일·비밀번호와 닉네임으로 가입. 가입 시 발송되는 인증 메일의 링크로 이메일을 인증해야 합니다. 비밀번호는 10자 이상·특수문자 포함. |
| 🎮 **Discord 가입** | Discord 로그인 한 번으로 계정 자동 생성. 커뮤니티(디스코드) 활동과 바로 연결되어 가장 편리합니다. |

> 가입을 진행하면 [이용약관](https://craftopia.work/terms) 및 [개인정보처리방침](https://craftopia.work/privacy)에 동의하는 것으로 간주됩니다.

## 계정 연동 (Discord · 마인크래프트)

서버를 온전히 이용하려면 **마인크래프트 정품 계정**과 **Discord**를 연동하는 것이 좋습니다. 연동은 모두 대시보드의 **[연결(Connections)]** 메뉴 또는 연동 허브(`auth.craftopia.work`)에서 진행합니다.

### 마인크래프트 정품 인증 — 두 가지 경로

1. **Microsoft 로그인 (권장)** — 대시보드에서 Microsoft 정품 로그인을 진행하면 UUID·닉네임이 자동으로 확인되어 연동됩니다. 인증 토큰은 저장하지 않습니다.
2. **인게임 코드 (폴백)** — 게임에 접속해 `/웹연동` 명령어로 발급된 코드를 대시보드에 입력해 연동합니다.

### Discord 연동

Discord 로그인(OAuth)으로 연결하거나, 인게임 봇 명령어로 연동할 수 있습니다. 연동하면 디스코드 역할(creator·official 등)이 웹·게임 권한과 자동으로 동기화됩니다.

## 서버 접속

- 마인크래프트 **정품(자바 에디션)** 클라이언트로 접속합니다. 권장 버전 및 최신 서버 주소는 **Discord 공지**에서 확인하세요.
- 서버는 건축 중심으로 운영되며, 비인가 모드·핵 클라이언트·허용되지 않은 맵(미니맵 등) 적용은 제한됩니다.
- 처음 접속하면 안내에 따라 `/웹연동`으로 웹 계정과 연결하면 인게임 활동이 대시보드에 반영됩니다.
