# 개요

BlockCanvas를 처음 이용하신다면 아래 세 단계만 따라오시면 됩니다.

1. [**플랫폼 연동**](signup.md) — 이메일 계정 만들기
2. [**계정 연동**](account-linking.md) — 마인크래프트 정품·Discord 연결
3. [**서버 접속**](connecting.md) — 게임에 접속해 건축 시작

{% hint style="success" %}
가입할 때 마인크래프트를 연동해 두면, 인게임 활동(영토·월드·코인)이 웹 대시보드에 자동으로 반영됩니다.
