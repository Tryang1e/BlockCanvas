# 서버 접속

## 인증체계

[**계정 연동**](account-linking.md) **과** [**플랫폼 연동**](signup.md) 을 모두 인증을 받아야합니다.

* **마인크래프트 정품 (자바 에디션)** 클라이언트
* 권장 버전 및 **최신 서버 주소** — Discord 공지에서 확인

{% hint style="warning" %}
서버는 건축 중심으로 운영됩니다. **비인가 모드·핵 클라이언트·허용되지 않은 맵(미니맵 등) 적용은 제한**됩니다.
{% endhint %}

서버 주소 : `mc.craftopia.work`

<figure><img src="../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure>

## 접속 후 처음 할 일

1. 서버에 접속합니다.
2. SHIFT + F 혹은 `/내정보`를 확인해보세요.

<figure><img src="../.gitbook/assets/image (10).png" alt=""><figcaption></figcaption></figure>

3. 연결되면 인게임 활동이 웹 대시보드에 자동 반영됩니다.

{% hint style="info" %}
서버 주소가 보이지 않으면 Discord 공지를 확인하거나 [문의](../undefined-4/help.md)해 주세요.
{% endhint %}
