# 개인 설정

| 명령어                                                | 설명                                     |
| -------------------------------------------------- | -------------------------------------- |
| [`/설정 itemsadder`](undefined.md#itemsadder-on-off) | 내 상태창을 프로필 카드가 아닌 마인크래프트 아이템창으로 오픈됩니다. |
| [`/설정 tp`](undefined.md#tp-on-off)                 | 누군가 당신에게 tp할 수 없습니다.                   |
| [`/설정 chat`](undefined.md#chat-on-off)             | 자신을 제외한 누구의 채팅도 보이지않습니다.               |
| [`/설정 mention`](undefined.md#mention-on-off)       | 맨션알림을 무시할 수 있습니다.                      |
| [`/설정 whisper`](undefined.md#whisper-on-off)       | 오는 귓말을 차단할 수 있습니다.                     |
| [`/설정 invite`](undefined.md#invite-on-off)         | 누구도 본인을 플롯, 월드, 스키매틱에 초대할 수 없습니다.      |
