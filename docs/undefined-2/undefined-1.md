# 건축 대시보드 ( 스키매틱 )

<figure><img src="../.gitbook/assets/image (42).png" alt=""><figcaption></figcaption></figure>

건축 대시보드의 '스키매틱' 버튼을 클릭하게되면 다음과 같이 본인의 스키매틱 클라우드가 열립니다.

해당 클라우드는 본인의 월드 클라우드 용량과 공유되며 용량이 초과되면 더이상 업로드가 불가능하니 주의바랍니다.

마인크래프트 FAWE의 schematic 파일(.schem)을 이용할 수 있으며, schematic 파일을 blueprint 파일(.bp)로 변환 할 수 있습니다.



&#x20;인 게임에서는 `//schem load 파일명` 을 통해 불러오거나 `//schem loadall 폴더명` 을 통해 폴더째로 불러올 수 있습니다. \
또한 저장의 경우 `//copy` 를 통해 복사된 건축물을 `//schem save 파일명` 으로 저장시 위 클라우드에 표시됩니다.

{% hint style="warning" %}
FAWE의 schmatic과 Axiom의 Blueprint의 경우 자세한 내용은 [FAWE 위키](https://intellectualsites.gitbook.io/fastasyncworldedit/features/main-commands-and-permissions#schematic-commands), [Axiom wiki](https://axiomdocs.moulberry.com/editor/windows/blueprints.html) 페이지를 확인바랍니다.
{% endhint %}
