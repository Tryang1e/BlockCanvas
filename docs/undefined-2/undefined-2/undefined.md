# 월드 초대/추방/권한/양도

### 월드 초대/추방

<figure><img src="../../.gitbook/assets/image (56).png" alt=""><figcaption></figcaption></figure>

월드 초대와 추방의 경우 기본적으로 플롯과 비슷하며, 초대할 닉네임을 기재 후 초대를 클릭하면 해당유저가 등록됩니다.

* 이때 '빌드(편집) 권한과 함께 초대'를 체크박스 클릭시 초대한 유저에게 빌드 권한을 부여합니다.

추방의 경우 '권한 ⅙' 옆 x 버튼을 클릭하면 추방됩니다.



### 월드 권한

<figure><img src="../../.gitbook/assets/image (59).png" alt=""><figcaption></figcaption></figure>

월드의 권한의 경우 다음과 같이 권한이 부여됩니다.

* 편집
  * 인게임 빌드 및 수정, fawe, axiom 활성화
* 게임룰
  * 게임룰 수정
* 백업
  * 백업 권한
* 다운로드
  * 다운로드 권한
* 초대
  * 초대 권한
* 추방
  * 추방 권한

해당 권한을 활성화 시 상대방의 대시보드에서도 위와 같은 기능들을 진행할 수 있습니다.
