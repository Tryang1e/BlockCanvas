# 건축 대시보드 ( 플롯 )

건축 대시보드를 통해 플롯을 구매, 삭제, 양도, 초대, 추방, 판매  할 수 있습니다.

**플롯은 최대 10개까지 구매가능**하며, 상점에서 [플롯 확장권](../../undefined-4/coins.md#undefined-1)을 구매하게되면 계속 점차 늘려갈 수 있습니다.
