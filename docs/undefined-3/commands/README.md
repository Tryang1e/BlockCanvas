# 인게임 명령어

대부분의 기능은 한글 명령어로 쓸 수 있고, 메뉴(GUI)로도 똑같이 할 수 있습니다. `< >` 는 직접 입력할 값입니다.

## 빠른 참조

| 명령어          | 설명                                                       |
| ------------ | -------------------------------------------------------- |
| `/설정`        | 본인의 [개인 설정](undefined.md)을 진행할 수 있습니다.                   |
| `/플롯 메뉴`     | [영토(플롯)](../../building/plots.md) 관리·안내 허브 메뉴를 엽니다.      |
| `/월드`        | 보유·초대된 [월드](../../building/world-cloud.md) 목록을 열어 입장합니다. |
| `/탐방`        | 다른 유저가 공유한 월드를 둘러봅니다.                                    |
| `/내정보`       | 내 상태창(계정 요약)을 엽니다.                                       |
| `/tp <플레이어>` | 요청 없이 즉시 그 플레이어에게 이동합니다.                                 |
| `/상점`        | 인게임 상점을 엽니다.                                             |

***

## 영토(플롯) 명령어

`/플롯` (별칭 `/영토`, `/pko`) 으로 영토를 관리합니다. 한글·영문 모두 됩니다.

### 메뉴 · 정보

| 명령어       | 설명                                           |
| --------- | -------------------------------------------- |
| `/플롯`     | 도움말(채팅)을 보여줍니다.                              |
| `/플롯 메뉴`  | 영토 관리·안내 허브 메뉴(GUI)를 엽니다.                    |
| `/플롯 단축`  | 자주 쓰는 기능만 모은 단축 메뉴를 엽니다.                     |
| `/플롯 홈`   | 내 영토 목록을 열어 선택해 이동합니다. `/플롯 홈 <번호>` 로 바로 이동. |
| `/플롯 상태`  | 내 상태창(보유 영토·용량 등 요약)을 엽니다. (= `/내정보`)        |
| `/플롯 정보`  | 지금 서 있는 영토의 소유자·멤버 등 정보를 봅니다.                |
| `/플롯 도움말` | 안내 메뉴를 엽니다. `/플롯 도움말 채팅 <1~5>` 로 텍스트 가이드.    |

### 분양 · 이동

| 명령어             | PlotSquared | 설명                                              |
| --------------- | ----------- | ----------------------------------------------- |
| `/플롯 구매`        | `claim`     | 지금 서 있는 빈 영토를 분양받습니다. (Dynmap에서 초록 마커 클릭으로도 가능) |
| `/플롯 자동`        | `auto`      | 비어 있는 영토를 자동으로 찾아 분양받습니다.                       |
| `/플롯 방문 <플레이어>` | `visit`     | 그 플레이어의 영토로 이동합니다.                              |

{% hint style="info" %}
보유 가능한 영토 수는 [등급](../ranks.md)에 따라 다르며, 상점의 **플롯 확장권**으로 늘릴 수 있습니다. 분양가(코인)는 월드(플롯 크기)마다 다릅니다.
{% endhint %}

플롯 월드로 바로 이동하는 명령도 있습니다.

| 명령어          | 이동 대상              |
| ------------ | ------------------ |
| `/plotworld` | 기본 플롯 월드 (100×100) |
| `/plot_300`  | 300×300 플롯 월드      |
| `/plot_500`  | 500×500 플롯 월드      |
| `/plot_1000` | 1000×1000 플롯 월드    |

### 멤버 · 권한

| 명령어               | PlotSquared | 설명                                                |
| ----------------- | ----------- | ------------------------------------------------- |
| `/플롯 초대 <플레이어>`   | `trust`     | 멤버로 신뢰(트러스트). **내가 접속 중이 아니어도** 그 멤버가 건축할 수 있습니다. |
| `/플롯 추가 <플레이어>`   | `add`       | 멤버 추가. **내가 접속 중일 때만** 그 멤버가 건축할 수 있습니다.          |
| `/플롯 제거 <플레이어>`   | `remove`    | 추가/신뢰한 멤버를 내립니다.                                  |
| `/플롯 추방 <플레이어>`   | `untrust`   | 신뢰(트러스트)를 회수합니다.                                  |
| `/플롯 차단 <플레이어>`   | `deny`      | 그 플레이어의 영토 출입을 막습니다.                              |
| `/플롯 차단해제 <플레이어>` | `undeny`    | 출입 차단을 해제합니다.                                     |
| `/플롯 강퇴 <플레이어>`   | `kick`      | 영토 안에 있는 그 플레이어를 내보냅니다.                           |

{% hint style="info" %}
초대받은(내 소유가 아닌) 영토에서 **내가 나가려면** 웹 대시보드에서 \[나가기]를 누르세요.
{% endhint %}

### 관리 · 설정

| 명령어                 | PlotSquared | 설명                                        |
| ------------------- | ----------- | ----------------------------------------- |
| `/플롯 설정 <항목> <값>`   | `set`       | 영토 설정(바닥·테두리 등)을 바꿉니다.                    |
| `/플롯 플래그 <플래그> <값>` | `flag`      | 영토 규칙(플래그)을 설정합니다.                        |
| `/플롯 생물군계 <생물군계>`   | `biome`     | 영토의 생물군계(바이옴)를 바꿉니다.                      |
| `/플롯 청소`            | `clear`     | 영토의 건축물을 초기화합니다. (소유는 유지)                 |
| `/플롯 삭제`            | `delete`    | 영토를 반납합니다. (건축 초기화 + 소유 해제, 다시 분양 가능 상태로) |

{% hint style="warning" %}
`/플롯 청소`·`/플롯 삭제` 는 되돌릴 수 없습니다. 실행 전에 꼭 확인하세요.
{% endhint %}

### 양도

웹 대시보드에서 양도를 신청하면, 받는 사람이 인게임에서 수락/거절합니다. (웹 대시보드에서도 가능)

| 명령어      | 설명                      |
| -------- | ----------------------- |
| `/플롯 수락` | 나에게 온 영토 소유권 양도를 수락합니다. |
| `/플롯 거절` | 나에게 온 영토 소유권 양도를 거절합니다. |

***

## 월드(클라우드) 명령어

`/월드` (별칭 `/world`, `/wko`) 로 개인 [월드 클라우드](../../building/world-cloud.md)를 입장합니다.

| 명령어           | 설명                                     |
| ------------- | -------------------------------------- |
| `/월드`         | 보유·초대된 월드 목록을 엽니다. (목록에서 클릭하거나 번호로 입장) |
| `/월드 입장 <번호>` | 목록의 N번째 월드로 입장합니다. (예: `/월드 입장 1`)     |
| `/월드 도움말`     | 월드 클라우드 안내 메뉴를 엽니다.                    |

{% hint style="info" %}
월드 업로드·다운로드·백업은 [웹 대시보드](https://craftopia.work)에서 합니다. 저장 용량(쿼터)은 [등급](../ranks.md)에 따라 다릅니다.
{% endhint %}

### 탐방 (다른 유저의 월드)

| 명령어           | 설명                                    |
| ------------- | ------------------------------------- |
| `/탐방`         | 다른 유저가 공유한 월드 목록을 엽니다.                |
| `/탐방 입장 <번호>` | 목록의 N번째 공유 월드로 이동합니다. (예: `/탐방 입장 2`) |

## 기타

| 명령어          | 설명                                                               |
| ------------ | ---------------------------------------------------------------- |
| `/내정보`       | 내 상태창을 엽니다. (= `/플롯 상태`)                                         |
| `/tp <플레이어>` | 요청 없이 **즉시** 그 플레이어 위치로 이동합니다(상대가 `/tptoggle` 로 허용한 경우, 관리자 예외). |
| `/tptoggle`  | 다른 사람이 나에게 `/tp` 로 이동할 수 있는지 켜고/끕니다.                             |
| `/상점`        | 인게임 상점을 엽니다.                                                     |
| `/설정`        | 본인의 개인 설정을 진행할 수 있습니다.                                           |

{% hint style="info" %}
명령어는 서버 업데이트에 따라 추가될 수 있습니다. 새 명령어는 Discord 공지와 본 문서로 안내합니다.
{% endhint %}
